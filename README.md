# 職場霸凌申訴調查程序時限管理系統 (Events Management)

本系統為專為人事主管與承辦人員設計之**離線即開即用、無外部網路依賴**的職場霸凌申訴程序時限管理工具。

## ✨ 核心特色

1. **單一網頁檔案（Zero Dependency）**
   - 直接以瀏覽器（Chrome、Edge、Safari 等）開啟 `index.html` 即可使用，不需架設伺服器或安裝任何執行環境。
2. **內建行政院人事行政總處（DGPA）官方行事曆**
   - 內建 2025 至 2027 年官方辦公日曆資料庫，自動判定工作日、週末、國定紀念日、彈性放假與補班日。
   - 嚴格依據《民法》始日不算入、期間末日逢假日順延至次一上班日之規定計算。
3. **長箭頭視覺化時間軸**
   - 清楚呈現各階段法定里程碑：
     - **接獲申訴**（起算基準日）
     - **受理決定**（法定 10 工作日內審查）
     - **通報主管機關**（受理後 7 個工作日）
     - **成立調查小組**（受理後 15 個工作日）
     - **完成調查報告**（成立後 2 個月日曆天）
     - **展延完成上限**（累計 3 個月日曆天）
   - 不予受理案件自動終結後續時程，時間軸精簡呈現申訴日與今天。
4. **一鍵複製時間軸照片（📷）**
   - 點擊時間軸右上角相機按鈕，即自動將時間軸渲染為高解析度圖片並寫入剪貼簿，可直接在公文、Word 或通訊軟體中按 `Ctrl + V` 貼上。
5. **雙重資料安全與實體檔案存檔**
   - 支援與同目錄下之 `霸凌申訴案件.json` 實體檔案進行本機雙向同步（File System Access API）。
   - 瀏覽器快取（LocalStorage）自動即時備份。
6. **案件排序管理**
   - 首頁案件列表預設以「最近編輯」排序。
   - 右上角提供排序切換按鈕，可一鍵切換為「截止排序」（依調查報告截止日由近到遠排序），按鈕寬度固定不抖動。

## 🚀 快速開始

直接用瀏覽器開啟專案中的 `index.html` 即可開始使用。
